# LumenBloom
LumenBloom is a 2D, sprite-based action platformer built in Python using Pygame. It focuses on tight platforming, evocative lighting & particle effects, and small, carefully-designed levels. The repo contains the playable game core, level scenes, entity logic (player, enemies, projectiles), visual/audio effects, and a simple UI/HUD system.

Key highlights:
- Four handcrafted levels (Grotto, Skybloom, Spire, Radiance) with unique hazards and gameplay twists
- Componentized code: core loop, scene manager, asset loader, effects, entities, UI and world systems
- Visual focus: bloom/lighting, particle systems, transitions and shockwaves
- Designed to be readable and mod-friendly for learning and experimentation

## Stack
- Language: Python 3.10+ (project targets Python 3.10+)
- Runtime / Framework: Pygame (game loop + rendering)
- Notable libraries: Pygame (or Pygame CE), common Python stdlib modules for assets/IO

## Quickstart — run the game
1. Clone repository
2. Create and activate a virtual environment
3. Install dependencies and run
